# Intent: แอดมินเข้าด้วย Auth0

| รายการ | ค่า |
| --- | --- |
| สถานะ | Confirmed |
| วันที่ยืนยัน | 2026-08-24 |
| ต้นทาง | grilling `/grill-me` ระบบแอดมินใช้ Auth0 เข้าสู่ระบบ |

## Confirmed statement

- **Outcome:** แอดมินเข้าได้สองทาง — ฟอร์มอีเมล/รหัสผ่านเดิม และปุ่ม Auth0; คนใหม่วออนุญาตในแอป คนที่อีเมลตรงกับ `User` เดิมเข้าได้เลย
- **User:** เจ้าหน้าที่ร้าน — คน seed คนแรกเป็นคนอนุญาต คนที่ถูกเปิดใช้ได้สิทธิ์แอดมินเท่ากันทุกคน
- **Why now:** อยากมี Auth0 เป็นประตูเสริม ไม่แทนที่รหัสผ่านที่มีอยู่
- **Success:** กดปุ่ม Auth0 แล้วเข้าคอนโซลได้ถ้าเป็นบัญชีเดิมหรือถูกอนุญาตแล้ว; คนใหม่เห็นหน้ารอ; หน้าผู้ใช้สวิตช์อนุญาต/ถอนได้; ฟอร์มรหัสผ่านยังใช้ได้; กดออกจากระบบแล้วออกแค่แอปนี้
- **Constraint:** ไม่แยก role; ถอนแล้วบัญชียังอยู่แค่เข้าคอนโซลไม่ได้; ต้องมี Auth0 application (OIDC) ใส่ใน `.env`; ทาง Auth0 รับเฉพาะอีเมล `@sru.ac.th` (รหัสผ่านของบัญชีที่มีอยู่ยังใช้ได้)
- **Out of scope:** ล็อกอินนักศึกษา/หน้าร้าน, SSO มหาวิทยาลัย, เอาฟอร์มรหัสผ่านออก, แยก role, ลบบัญชีตอนถอน, ออกจาก Auth0 ด้วย, ตั้งรหัสผ่านให้คนที่เข้าได้แค่ Auth0

## Decisions captured during grill

| หัวข้อ | คำตอบ |
| --- | --- |
| รหัสผ่านเดิม | คงไว้ — เพิ่มปุ่ม Auth0 คู่กัน |
| ใครเข้าคอนโซลได้ | คนใหม่วออนุญาต; อีเมลตรง User เดิมเข้าได้เลย |
| อนุญาตที่ไหน | ในแอป หน้าผู้ใช้เล็กๆ สิทธิ์เท่ากัน ไม่แยก role |
| ถอนสิทธิ์ | สวิตช์อนุญาต/ถอน บัญชียังอยู่ |
| ออกจากระบบ | แค่แอปนี้ ไม่ SLO Auth0 |
| โดเมน Auth0 | เฉพาะ `@sru.ac.th` — รหัสผ่านไม่จำกัดโดเมน |

## Non-goals (ชัดเจน)

- ล็อกอินนักศึกษา / หน้าร้าน
- SSO มหาวิทยาลัย
- แพ็กเกจ `auth0/login` เป็น auth หลัก
- Spatie / roles แยก
- ลบบัญชีตอนถอน
- Auth0 logout / SLO
