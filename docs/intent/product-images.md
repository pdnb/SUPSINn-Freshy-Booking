# Intent: รูปภาพสินค้า (product image gallery)

| รายการ | ค่า |
| --- | --- |
| สถานะ | Confirmed |
| วันที่ยืนยัน | 2026-08-15 |
| ต้นทาง | grilling — ใส่รูปภาพสินค้า |
| ลำดับ | หลัง v2 (ครบทั้ง 5 slice แล้ว) |

## Confirmed statement

- **Outcome:** สินค้ามีรูปจริง หลายรูปต่อสินค้า เลื่อนดูแบบ gallery ได้
- **User:** นักศึกษา — เห็นรูปตอนตัดสินใจซื้อ / แอดมิน — อัปโหลดและจัดการรูปเอง
- **Why now:** v2 ครบทั้ง 5 slice แล้ว แต่หน้าร้านยังเป็นกล่อง placeholder สีเทา
- **Success:** แอดมินอัปโหลด/ลบ/เรียงรูปได้ในฟอร์มสินค้าเดิม (`admin/products` form); การ์ดหน้าแรกโชว์รูปปก; หน้ารายละเอียดเป็น gallery เลื่อนได้ (สไตล์เดียวกับ carousel แบนเนอร์); สินค้าที่ยังไม่มีรูปยังแสดง placeholder เดิม ไม่พัง layout
- **Constraint:**
  - ใช้ public disk + แพทเทิร์นเดียวกับ `AdsBanner` (store ใต้โฟลเดอร์ + method `url()`)
  - ไม่เปลี่ยนกฎสินค้า/ออเดอร์เดิม (`CatalogService`, `OrderService`)
  - แอดมินใช้ `<x-admin.*>` primitives; ไอคอนผ่าน `<x-icon>` เท่านั้น
- **Out of scope:**
  - รูปในตะกร้า / ใบเสร็จ / หน้า list แอดมิน
  - รูประดับ option ย่อย (ไซส์/สี)
  - วิดีโอ, image zoom
  - orphan cleanup เมื่อลบสินค้า (known limitation — ตอนนี้แอดมินไม่มีปุ่มลบสินค้า)

## Decisions captured during grill

| หัวข้อ | คำตอบ |
| --- | --- |
| รูปโชว์ที่ไหน | การ์ดสินค้าหน้าแรก + หน้ารายละเอียดสินค้า |
| รูปเข้าระบบยังไง | อัปโหลดผ่านฟอร์มสินค้าในแอดมิน (ไม่ผูกผ่าน seed) |
| กี่รูปต่อสินค้า | หลายรูป แบบ gallery เลื่อนดูได้ → ตารางแยก `product_images` |
| ไม่มีรูป | แสดง placeholder เดิม (กล่องเทา + คำว่า สินค้า/ชุด) |
| รูปปกหน้าแรก | รูปแรกตาม `sort_order` (`coverImage`) |
| สไตล์ gallery | คัดลอกโครง carousel แบนเนอร์หน้าแรก (Alpine index/next/prev, ไม่ auto-play) |

## Non-goals (ชัดเจน)

- รูป variant ตามตัวเลือก (ไซส์/สี/เพศ)
- รูปในออเดอร์/ใบเสร็จ/สรุปยอดโรงงาน
- บังคับอัปโหลดรูปตอนสร้างสินค้า
