สไลซ์เดียว — พิมพ์ใบ checklist ต่อออเดอร์ ไม่ใช่ใบปะหน้า ไม่เชื่อมขนส่ง ไม่เปลี่ยนสถานะตอนพิมพ์

## Confirmed statement

- **Outcome:** หน้าแอดมินใหม่สำหรับพิมพ์กองใบ checklist หนึ่งออเดอร์ต่อหน้า ให้เจ้าหน้าที่ถือกระดาษไปโต๊ะแพ็ค
- **User:** เจ้าหน้าที่แพ็คของ — ทุกช่องทาง (ไปรษณีย์ / ร้าน / หอ)
- **Why now:** ที่โต๊ะแพ็คต้องติ๊กของจากกระดาษ ไม่สลับจอออเดอร์ทีละใบ
- **Success:** กรองรอบจอง / ช่องทาง / คณะ แล้วพิมพ์ PDF ทั้งกอง; เรียง **ช่องทาง (ไปรษณีย์ → ร้าน → หอ) → คณะ → รหัสออเดอร์**; แต่ละใบมีผู้จองครบ (ชื่อ, รหัสนักศึกษา, โทร, คณะ, สาขา, ช่องทาง, ที่อยู่หรือจุดรับ) + รายการ/ไซส์/จำนวน + ช่องติ๊กว่าง; พิมพ์แล้วสถานะในระบบไม่เปลี่ยน — ยังกดจัดส่งแล้ว/พร้อมรับบนหน้าเดิม
- **Constraint:**
  - Livewire SFC หน้าแอดมินตามเดิม ไม่ใช่ Filament
  - PDF แนวเดียวกับสรุปยอด (DomPDF + Sarabun)
  - กองเริ่มต้น = confirmed + พร้อมรับ + ไปรษณีย์ที่ยังไม่มีเลขพัสดุ (ไม่เอา pending / ขอสลิปใหม่ / ยกเลิก / รับครบ / จัดส่งแล้วที่มีเลข)
  - ชื่อที่คนเห็นคือ **แพ็คของ** (เมนู ชื่อหน้า หัวข้อ/ไฟล์ PDF) — ไม่ใช้ ใบแพ็ค / แพ็คสินค้า
- **Out of scope:**
  - ใบปะหน้าขนส่ง
  - เชื่อมไปรษณีย์/Kerry
  - ยอดหยิบรวมแบบสรุปยอด
  - ติ๊กบนจอแล้ว sync
  - ราคา/ยอดเงินบนใบ
  - LINE / SMS
  - เปลี่ยนสถานะตอนพิมพ์
  - เช็คลิสต์ฝั่งนักศึกษา
  - CSV / Excel
  - Filament

## Decisions captured during grill

| หัวข้อ | คำตอบ |
| --- | --- |
| สิ่งที่ต้องการ | ใบ checklist พิมพ์ออกมาได้ ถือไปโต๊ะแพ็ค |
| หน่วยของใบ | หนึ่งออเดอร์หนึ่งใบ — ไม่ใช่ยอดรวมหยิบ |
| ช่องทาง | ทุกช่องทาง (ไปรษณีย์ / ร้าน / หอ) |
| วิธีพิมพ์ | กองทีเดียว: กรองแล้วพิมพ์ PDF ทั้งกอง หนึ่งออเดอร์ต่อหน้า |
| ฟิลด์บนใบ | ผู้จองครบ (ชื่อ, รหัสนักศึกษา, โทร, คณะ, สาขา, ช่องทาง, ที่อยู่หรือจุดรับ) + รายการ/ไซส์/จำนวน + ช่องติ๊ก — ไม่มีราคา |
| สถานะที่พิมพ์ | confirmed + พร้อมรับ + ไปรษณีย์ที่ยังไม่มีเลขพัสดุ |
| เรียงกอง | ช่องทาง → คณะ → รหัสออเดอร์; ลำดับช่องทาง = ไปรษณีย์ → ร้าน → หอ |
| ที่อยู่ปุ่ม | หน้าแอดมินใหม่ **แพ็คของ** |
| พิมพ์แล้วสถานะ | ไม่เปลี่ยน — กดจัดส่งแล้ว/พร้อมรับบนหน้าเดิม |
| ช่องติ๊ก | ทีละบรรทัดสินค้า (ไม่ใช่ทีละตัวเลือก) |

## Non-goals (ชัดเจน)

- ใบปะหน้า / พิมพ์ที่อยู่แยก / เชื่อมขนส่ง
- ยอดหยิบรวมสินค้า × ตัวเลือก (มีอยู่แล้วที่สรุปยอด)
- ติ๊กบนจอแล้วบันทึก
- ราคา ยอดสุทธิ สลิป เลขพัสดุ บนใบ
- LINE/SMS, verifier, roles, API โรงงาน, Filament
- เช็คลิสต์นักศึกษา
