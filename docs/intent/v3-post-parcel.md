## Confirmed statement

- **Outcome:** แอดมินบันทึกเลขพัสดุ (optional, ข้อความว่าง) ตอนกดจัดส่งแล้วบนแท็บไปรษณีย์ แล้วนักศึกษาเห็นเลขนั้นบนหน้าติดตาม
- **User:** เจ้าหน้าที่ 1–ไม่กี่คนที่แพ็คของส่ง; นักศึกษาที่รอพัสดุ
- **Why now:** v2 ตัดเลขพัสดุไว้; mockup มีช่องแล้ว; `tracking_token` คือลิงก์ดูออเดอร์ ไม่ใช่เลขพัสดุ
- **Success:**
  - กดจัดส่งแล้วได้โดยมีหรือไม่มีเลข
  - ใส่/แก้ย้อนหลังบนออเดอร์ shipped
  - คิว “รอดำเนินการ” ของแท็บ post = confirmed + shipped ที่ยังไม่มีเลข
  - หน้า confirmation ของ post เป็น จองแล้ว → ตรวจสลิป → จัดส่งแล้ว (จบที่ shipped)
- **Constraint:**
  - Livewire SFC + `OrderService`
  - คอลัมน์ใหม่คนละตัวกับ `tracking_token`
  - ไม่เปลี่ยนกฎ pickup / bookstore / hall
  - ไม่มีปุ่มปิด completed สำหรับ post
- **Out of scope:**
  - ใบปะหน้า / พิมพ์ / packing list
  - เชื่อมขนส่ง
  - LINE / SMS
  - verifier
  - roles
  - API โรงงาน
  - เช็คลิสต์นักศึกษา
  - รวมหน้าจัดส่งกับรับของ
  - Filament

## Decisions captured during grill

| หัวข้อ | คำตอบ |
| --- | --- |
| ขอบเขต “v3” | สไลซ์เดียว — ไม่ใช่โปรแกรมที่เรียง LINE / verifier / roles ต่อ |
| งานพอแล้ว | ช่องเลขพัสดุตอนกดจัดส่งแล้ว + โชว์แอดมินและนักศึกษา — ไม่พิมพ์ ไม่เชื่อมขนส่ง |
| ช่องทาง | ไปรษณีย์อย่างเดียว — ร้าน/หออยู่หน้า รับของ ตามเดิม |
| นักศึกษาเห็นเลข | เห็นบนหน้าติดตาม / confirmation |
| บังคับเลขตอนส่ง | ไม่บังคับ — ส่งได้ก่อนได้เลข |
| แก้หลังส่ง | ได้ — ใส่/แก้/ล้างบนออเดอร์ shipped (shipped คือจบงาน ไม่มี UI completed) |
| รูปแบบ | ข้อความว่าง — ไม่บังคับ pattern ไปรษณีย์; ค่าว่างเก็บ `null` |
| ปิดลูป completed | ไม่มี — shipped คือจบสำหรับ post |
| ขั้นสถานะนักศึกษา (post) | จองแล้ว → ตรวจสลิป → จัดส่งแล้ว (จบเมื่อ shipped) ไม่มีขั้น “รับแล้ว” |
| คิวรอดำเนินการ post | confirmed + shipped ที่ยังไม่มีเลข — ล้างเลขแล้วออเดอร์กลับเข้าคิวนี้ |
| UI ช่องเลข | คัดลอกคำว่า เลขพัสดุ จาก mockup แต่ใส่ในแผงรายละเอียดที่มีอยู่ ไม่ใช้ไดอะล็อกครั้งเดียว เพราะเลขแก้ได้ |

## Non-goals (ชัดเจน)

- ใบปะหน้า / พิมพ์ที่อยู่ / packing list
- เชื่อมไปรษณีย์ไทย / Kerry หรือสร้างเลขอัตโนมัติ
- URL ติดตามของผู้ขนส่ง
- ปุ่ม “ส่งถึงแล้ว” / ปิด `completed` สำหรับ post
- เปลี่ยนกฎ bookstore / hall / pickup
- ใช้ซ้ำ `tracking_token` เป็นเลขพัสดุ
- reverse transition จาก shipped
- แจ้งเตือน LINE/SMS, verifier, roles, API โรงงาน, Filament
