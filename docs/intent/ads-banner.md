# Intent: โมดูล ads banner

| รายการ | ค่า |
| --- | --- |
| สถานะ | Confirmed |
| วันที่ยืนยัน | 2026-08-15 |
| ต้นทาง | grilling — เพิ่มโมดูล ads banner |
| ลำดับ | หลัง v1 (จอง–สลิป–รอบเปิดใช้ได้แล้ว) |
| SRS v1 | ไม่บล็อกรับมอบ — ยังไม่อยู่ใน `docs/srs.md` |

## Confirmed statement

- **Outcome:** แอดมินอัปโหลดรูปแบนเนอร์เลื่อนแบบ Shopee บนหน้าแรก แตะแล้วเปิด URL นอกเว็บที่วางเองได้
- **User:** เจ้าหน้าที่เป็นคนจัดการ; นักศึกษาเป็นคนเห็น/แตะ
- **Why now:** อยากได้โมดูลยืดหยุ่นแบบหน้าร้าน แต่ยังไม่มีรูป/ลิงก์จริง — ทำหลังจอง–สลิป–รอบเปิดใช้ได้แล้ว
- **Success:** แอดมินเพิ่ม/เรียง/เปิด–ปิด รูป+URL ได้; มีแบนเนอร์ก็เลื่อนบนหน้าแรก ไม่มีก็ซ่อนช่อง; แตะแล้วออกเว็บตาม URL
- **Constraint:**
  - ไม่ใช่ระบบโฆษณาคนนอก
  - URL เป็นช่องว่างๆ ไม่ผูกสินค้า
  - ไม่บล็อกรับมอบ v1
- **Out of scope:**
  - ขายพื้นที่โฆษณา / โฆษณาบุคคลที่สาม
  - นับคลิก / ยิงเป้า
  - ผูกแบนเนอร์เป็นหน้าสินค้า (โมเดลหลักคือ URL นอกเว็บ)
  - หลายตำแหน่งในเว็บ (หน้าแรกช่องเดียว)
  - ตารางเวลาเริ่ม–จบ
  - ไม่ทำใน v1 — หน้าแรก v1 ใช้ข้อความคงที่ใน mockup (`home-banner`) ไปก่อน

## Decisions captured during grill

| หัวข้อ | คำตอบ |
| --- | --- |
| งานจริง | CMS ให้เจ้าหน้าที่สลับโปรโมทหน้าร้าน ไม่ใช่ขายโฆษณา |
| รูปแบบบนจอ | รูปแบนเนอร์เลื่อนแบบ Shopee ไม่ใช่กล่องข้อความแก้ได้อย่างเดียว |
| แตะแล้ว | ลิงก์ออกเว็บ |
| ปลายทาง URL | ช่องว่างๆ ให้แอดมินวางทีหลัง ไม่มีเป้าวันนี้ |
| ลำดับในโปรเจกต์ | ทำทีหลัง — งานจอง–สลิป–รอบเปิดสำคัญกว่า และยังไม่มีคอนเทนต์ |
| ตำแหน่ง | หน้าแรกช่องเดียว (slot `home-banner`) |
| ไม่มีแบนเนอร์ | ซ่อนช่อง |

## Non-goals (ชัดเจน)

- Ad network / impression / targeting
- Deep link ไปหน้าสินค้าเป็นชนิดลิงก์หลัก
- ทำพร้อมรับมอบ v1
